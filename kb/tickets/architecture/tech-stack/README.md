# Tech Stack

## Components

- **Language**: Rust (CLI, core, LSP)
- **Scripting**: Rhai (embedded scripting engine for .vibe files)
- **Audio Engine**: SuperCollider (open-source synthesis)
- **Audio Driver**: JACK Audio (Linux/Mac)
- **Protocol**: OSC (Open Sound Control) for SuperCollider communication
- **Package**: `cargo install vibelang-cli` (crates.io)
