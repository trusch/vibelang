# Effects Overview

Effect synthdefs applied via `fx()` on group buses.

## Reverbs

`stdlib/effects/reverbs/` — reverb, hall_reverb, plate_reverb, room_reverb, shimmer_reverb

## Delays

`stdlib/effects/delays/` — delay, ping_pong_delay, dub_delay

## Filters

`stdlib/effects/filters/` — lowpass, moog_filter

## Dynamics

`stdlib/effects/dynamics/` — compressor, limiter

## Modulation

`stdlib/effects/modulation/` — chorus, phaser

## Distortion

`stdlib/effects/distortion/` — distortion, overdrive, bitcrush
